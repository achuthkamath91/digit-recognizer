Two ideas you can touch

Softmax, loss and learning rate

Softmax and cross-entropy loss

The network outputs raw scores. Softmax turns them into probabilities that sum to 1. The loss is −ln(probability given to the correct class). Move a score and watch the loss.

Gradient descent and learning rate

Training repeatedly moves a weight w downhill: w ← w − lr × slope. Here the loss is (w − 2)², so the best value is w = 2.

The part that learns

One training step, line by line

This is the whole learning rule from digits.py, run on 64 images at a time. Open a line to read what it does. Shapes are shown for a batch of 64.

h, probs = forward(p, x)
dz = (probs - t) / len(b)
dh = (dz @ p["W2"].T) * (h > 0)
p["W2"] -= lr * h.T @ dz;  p["b2"] -= lr * dz.sum(0)
p["W1"] -= lr * x.T @ dh;  p["b1"] -= lr * dh.sum(0)
h, probs = forward(p, x) (64,784) → (64,128) → (64,10)

The forward pass you saw above, for 64 images at once. h is the hidden layer after ReLU, probs the softmax output.

dz = (probs - t) / len(b) (64,10)

t is the correct answer as a one-hot row. Subtracting it from the probabilities is the gradient of cross-entropy loss with respect to the scores. A confident correct guess gives values near 0. Dividing by 64 averages over the batch.

dh = (dz @ W2.T) * (h > 0) (64,128)

Backpropagation: send the error backwards through the second layer's weights to find how much each hidden neuron contributed. Multiplying by (h > 0) is the ReLU derivative. A neuron that was switched off gets no blame and no update.

W2 -= lr * h.T @ dz (128,10)

Move each second-layer weight against its gradient. A weight linking a very active neuron to a class that was wrongly favored gets pushed down the most. b2 follows with the column sums.

W1 -= lr * x.T @ dh (784,128)

The same rule for the first layer. Pixels that were bright when a neuron deserved blame get their weights changed. This is how the tiles above gradually became stroke detectors.

Settings used: 10 epochs, batch 64, learning rate 0.1, 128 hidden neurons, He initialization (random weights scaled by √(2 / inputs), which keeps ReLU layers from fading out). Each epoch visits all 60,000 training images once in shuffled order.
